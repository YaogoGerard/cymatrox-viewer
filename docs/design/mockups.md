# Design mock-ups

Screenshots of the original interface prototype, kept as a visual reference for
the control panel layout, the frequency ruler and the stage captions. They were
captured from the single-file HTML mock-up that used to live at the repository
root; that file has since been removed, so these images are the remaining copy.

| Image | Board | Shows |
| --- | --- | --- |
| `01-granular-streaming.png` | Granulaire · streaming | Granular selected, 440 Hz, granular physics, `STREAMING` |
| `02-fluid-streaming.png` | Fluide · streaming | Fluid selected, 60 Hz, liquid physics |
| `04-granular-error.png` | Granulaire · erreur | Solver-rebuild failure banner |
| `05-fluid-starting.png` | Fluide · démarrage | Startup, `Initialisation du solveur…`, `STARTING` |

Each image is 2880 × 1720 (the mock is laid out at 1440 × 860, captured at 2×).

## These are historical

The mock does **not** reflect the shipped interface:

- The strings are **French**; the app now ships in English (commit `d4ad1fc`).
